# 工科技术与课程报告排版与核验

目标是在严格保留原模板结构与样式的前提下，完成工科 Word 报告的内容润色、一手数据对齐、规范排版与 PDF 交付核验。

## 工作流程

1. **备份与盘点**：改动前在独立临时目录保留原 `.docx` 副本。读取模板及现有报告，先运行 `scripts/check_report_docx.py <报告路径或目录>` 掌握段落、表格、插图、公式、图表编号与字体现状。
2. **个人信息与边界**：封面、任务书、调查表中的姓名、学号、班级、专业、学院、指导教师、日期与签字，在用户明确提供前保持留空；不擅自改写原始任务书要求或调查表结构。
3. **一手数据与图文对齐**：
   - 正文数值、边界条件、材料、公差、工艺参数与插图必须核对同一对象、同一方案的一手来源（工程图、求解 `.dat`/`.f06`、工艺卡/NC、实验日志）；
   - 同类物理量单位统一（正文力用 `N`、压力与应力用 `MPa`、频率用 `Hz`），尽量把单位放到表头；
   - 发现旧文与一手文件冲突时，按一手文件修正并记录取舍，不凭印象编造高阶振型、应力、误差或检验结论；明确区分归一化模态振型位移与真实物理变形。
4. **工程写作风格**：
   - 用清晰、克制的工程术语说明做了什么、观察到什么、结果对应哪个结构或工艺特征；
   - 消除口语化表达、泛泛空话以及“仅供参考/可能存在误差”等防御性兜底套话；
   - 保留必要的理论公式（优先可编辑 Word 公式），说明变量含义并结合实际尺寸或工况解释结果。
5. **版式、字体与表格规范**：
   - 严格遵循目标模板的纸张（通常 A4 纵向）、页边距、标题层级与行距（常见中文正文宋体小四、固定 24 磅行距，标题黑体，西文及数字 Times New Roman）；
   - 正文数据表采用标准三线表（顶线、表头下线、底线），表内小字号不缩进、数字列右对齐、说明列左对齐；任务书、调查表及原工艺卡截图沿用原样式；
   - 图用章内编号（如 `图3-1`）置于图下，表题置于表上，正文引用与编号严格一一对应；图与图注、短表保持同页，避免标题单独落在页末或为少量内容空起新页。
6. **安全导出与逐页核查**：
   - 详见 [Word 自动化与排版避坑](references/word-automation.md)；
   - 运行 `scripts/export_report_pdf.py` 刷新分页/目录并导出 PDF（Word COM 异常或阻塞时自动切回 LibreOffice 独立 profile，防止僵尸 `WINWORD.EXE` 锁死文件）；
   - 导出后复跑 `scripts/check_report_docx.py` 核对 ZIP 与编号，并抽查/逐页查看 PDF 页面，确认目录页码与正文一致、无乱码、无孤行断表、插图读数和色标清晰。

## 按需读取的资源

- [Word 自动化与排版避坑](references/word-automation.md)：`python-docx`/XML 精细改稿、保留公式与上下标、三线表设置及 Word COM / LibreOffice 安全导出要点。
- `scripts/check_report_docx.py`：只读体检 `.docx` 的 ZIP 完整性、页面尺寸、图表/公式数量、图表编号重复与断号、字体分布及遗留占位符。
- `scripts/export_report_pdf.py`：安全调用 Word COM（带 `Visible=False` / `DisplayAlerts=0` / `finally` 退出）或 LibreOffice 独立 profile 导出 PDF 并输出各章页码。
