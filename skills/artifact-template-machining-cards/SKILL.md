# 机械加工工艺卡

使用 `artifact-template.json` 指定的 `assets/reference.docx` 作为版式依据；模板不带学校名称。参考模板中的零件、材料、参数、程序、签名和示例图片只是样例，制作新卡时替换，不当作当前任务的技术输入。标准与参考资料保存在 `assets/standards/`。

## 工作方式

1. 从用户指定的当前交付目录读取零件图样、CAM主工程说明、工序与NC清单，确定本次零件及输出位置。不要仅凭文件修改时间选择主工程；发现旧报告与新NC不同，按当前文件核实并在工作记录解释取舍。
2. 在用户原有路线基础上核对毛坯、材料、热处理、基准、装夹、粗精加工与孔螺纹及特种加工。课程设计允许合理选用理论工艺参数；设计选值与CAM实际值的来源放在独立对照记录，正文直接写加工要求。详见 [工艺与参数](references/engineering.md)。
3. 复制模板 `assets/reference.docx` 后，通过 `zipfile`+XML 精确改表或 `python-docx` 填写（详见 [Windows工具链](references/windows.md)）。每件一页过程卡，每个主要工序一页工序卡；按实际内容增减页，不固定五页。保留A3横向、表格字段、宋体/黑体及边框层级；机构栏默认空白，不补学校名称。替换示例签名，签审栏留空。不要重做成Markdown、CSV或普通报告。
4. 工序图用AutoCAD生成DWG及插图PNG，表达该工序结束时的形状。优先修正泛化矩形、缺失叉槽或台阶、看不到成形结构的问题。末道加工工序图可在原图框内组合整体轴测形状与本工序局部装夹图；默认不另加最终成品对照页。详见 [工序图](references/drawings.md)。
5. 核对过程卡与工序卡的工序号、名称、设备、刀具和参数，以及图文尺寸的一致性。DOCX导出PDF，逐页渲染查看，修正表格跨页、乱码、压线和溢出；页数不因换图意外增加。文本扫描和页数检查不能代替看图。
6. 按零件分别整理DOCX、PDF和对应DWG/PNG；需要时生成合订本。独立说明记录输入来源、设计参数和实际检查内容，正文不加入免责、防御性套话，也不在图下增加自我解释的兜底句。仅申明实际做过的检查，不把静态核对写成重新仿真或实物检验。

## 文件与修改边界

- 保留用户源三维、二维图与CAM主工程。需要几何信息时只读导出到本任务工作目录；不得为绘图修订源模型。
- 使用已有的CAD/NX排他锁约定；申请用O_EXCL，用完释放自己的锁。锁被占用时先做离线工作，不删他人锁、不结束用户进程、不操作用户CAD界面。
- 优先修改已授权的当前版本，并保留无关编辑。清理须由用户授权，先确认最新交付齐全及副本一致，再删除旧版、预览、日志和临时配置。保留模板、参考标准和必要的生成源文件。

## 按需读取的资源

- `assets/reference.pdf`、`assets/preview.png`：去学校名称的模板外观；保留参考DOCX原样，输出时复制修改。
- `assets/standards/机床夹具设计指导_第三章_定位夹紧符号.pdf`：定位、夹紧符号参考，是保留的教材章节，不把它称为已核验的现行国家标准。
- [Windows工具链](references/windows.md)：本机LibreOffice与AutoCAD的可靠入口和PDF渲染回退。
- `scripts/sheetgen.py`、`scripts/skutil.py`：可选的AutoLISP二维图元及装夹绘图辅助；按本任务图样设定尺寸，不沿用示例公差、材料或固定零件参数。
- `scripts/inspect_cards.py`：只读汇总DOCX页面设置、嵌图数量与PDF页数；几何及工艺正确性仍需依据输入核对。
