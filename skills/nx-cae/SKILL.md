# NX CAE 工程与交付

目标是交付可在 NX 中编辑、直接求解并读取结果的工程。外部 DAT 求解成功只证明该输入成功，不能据此声称交付 SIM 可复现。

## 先识别当前权威版本

- 确认用户最新手动修改的 SIM、关联 FEM/PRT、解算方案及步骤；不要用旧脚本或报告覆盖用户工况。用户说“只需重算”时保留其材料、边界、载荷，发现疑点另行明确报告。
- 区分诊断、工况修复、重算和文件整理。整理不包括擅自修改物理设置；已授权的修复按件完成，不仅提交方案。
- NX/CAE 操作遵守项目 CAD_SESSION.lock 的现有约定。独占创建锁，记录所属任务，只释放本任务持有的锁；占用时不强删、不结束其他 CAD 进程。使用现有包装器前先核查其行为。
- 改动前保留可恢复副本，源模型和原图保持不动。修改用户指定正式 SIM 的授权只覆盖指定修改，不扩展到重建其他载荷或覆盖报告。
- 有界面手动未保存内容时，优先在当前会话处理；后台 journal 不得覆盖磁盘后再让旧 GUI 会话保存回来。界面不可连接时说明真实接口错误，使用可验证的 API 路径处理副本，不冒称 GUI 已修改。

## 工况与原生对象

- 从装配关系确认支承、销轴、螺栓、轴承和接触面的传力路径。允许按用户授权作工程推测，须记录几何依据、面积、方向、数值来源及待确认项。禁止把网格遍历的前几个面当作真实传力面。
- 使用少量可编辑的 NX 原生面力、承压、力矩及重力对象。不要每个节点建立一个 ComponentForceField。原生面力导出成多条 FORCE 是正常离散化，不能仅因 DAT 存在大量 FORCE 就断言 SIM 有大量节点载荷对象。
- 自重使用原生 Gravity/Acceleration 与材料密度；方向按装配竖直方向确定，不能默认孤立件 -Z。不要重复叠加已混入旧力场的自重。
- 用户不要气压时不要继续加载腔压；保留的机械推力或扭矩应有独立工况或明确等效来源，不能仅改名。压力与其等效力不能重复计入。
- 不把所有孔壁全固定。对销连接明确径向、轴向和转动自由度；对简化节点支承识别局部奇异峰值，不能直接作强度验收。
- 正常工况一般为机械工作载荷与 1g 同时作用；过载系数作用于工作载荷，重力不随意放大。系数及安全系数由任务或明确假设给出，不把本项目 1.5 倍推广为通用标准。
- 材料字段“未指定”不能作为已分配证据。检查 FEM 材料、单元属性及导出 MAT1；强度需对应材料状态。HT200 用适合脆性材料的主应力/强度判据，不能套钢材屈服判据。

## 导出、求解与结果

执行前读 [求解检查](references/solver-checks.md)；涉及 NX 12 批量修复模态方案、绑定 `.op2` 结果或自动抓取原生后处理云图截图时，读 [NX 12 自动化与截图](references/nx12-automation.md)。修改原生对象后核查其挂接到正确方案/步骤，并验证导出输入中的载荷、约束、材料及输出请求。对象提交成功不等于参与本次求解。

完成证据分开报告：原生设置已保存、输入已导出、求解成功、结果可读、物理工况已核对。未经验证不跨级声明。不能编造应力、频率、云图、收敛或安全系数；用户要求软件原生截图风格时，不得用 matplotlib/PyVista 等外部绘图冒充 NX 原生云图。

模态区分普通约束模态、自由模态与预应力模态；普通 SOL103 不因存在静载就自动包含预应力，且**新建 SOL103 方案默认不会继承静力学约束**——务必核查约束挂载、Lanczos（`EIGRL`）提取卡、独立模态输出请求（关闭 Stress/SPC Forces 以免 `.op2` 暴涨并防止污染静力方案）以及 `ResultReference` 的本地路径与单位制一致性。网格敏感性比较须保持同一物理约束位置；振型换序时按振型对应关系比较，不只比较阶次。尖角峰值不收敛时明确限制，采用有物理依据的固定位置路径评价，不删点凑合格。

## 文件整理与按需资源

- 按 [交付整理](references/delivery.md) 操作。最新工程及结果原名原位优先保留；过时记录归档到正式目录之外。文件成功和日志成功不等于已在 NX 重开或工况验收成功。
- 无需启动 NX 即可快速体检目录体积、`.dat` 单位/材料/约束/输出请求、`.f06` 固有频率与有效质量及 `.log` 完成状态：运行 `scripts/inspect_cae.py <工程目录>`。
- 需只读核查 `.sim` 内各方案约束挂载、Lanczos、输出请求是否共用及 `CreateSolutionResult` 可读性：设置 `CAE_SIM_PATH` 与 `CAE_LOG_PATH` 后通过 `run_journal.exe` 运行 `scripts/check_sim_nxopen.py`。
