# 求解检查与无结果诊断

## 当前数据优先

先读取最新 DAT 的头部、CASE CONTROL、材料和载荷卡及最新 LOG/F06 的末尾。按路径和时间对应 SIM、方案名与结果，避免读到旧 static.op2。读取系统进程只为判断运行状态，不结束用户求解进程。

1. 正在计算：检查进程、CPU 累计变化及日志进度；矩阵排序/分解阶段可能长时间不刷新。读取 5293、6916 等消息本身不能判断卡死。报告实际规模与进度，不编造剩余耗时。
2. 已终止：查完整 FATAL/错误上下文。7555 表示部分单元几何质量超限，需要检查元素及影响，不等于求解必然失败，也不能仅靠放宽阈值消除问题。
3. 正常完成：交叉核查 Linear static analysis completed / Normal modes analysis completed、Analysis complete 0、END OF JOB 和非空结果文件；启动器返回码或 OP2 大小单独不能证明结果有效。
4. 无可见结果：检查请求的结果表是否实际写入 OP2，以及 NX 结果关联路径、当前方案和结果加载状态。不能看到 0 字节 OP2 就忽略仍在运行的求解进程。若重算后打开 `.sim` 仍无法看图，核查 `.sim` 是否在求解/修改后重新保存，以及 `ResultReference` 是否指向当前本地 `.op2` 且单位制与静力/求解单位一致（`Kilogram` 与 `Tonne` 混用会导致读数差 1000 倍或加载异常）。

## 模态分析（SOL 103）专项核查

1. **漏挂约束与刚体模态**：新建 `SOL 103` 不会自动继承 `SOL 101` 的约束。若前 6 阶出现接近 `0 Hz`（如 `0.0006–0.0009 Hz`）的频率，首先查 `.dat` / `.diag` 中是否存在 `SPC`；约束模态必须将对应约束显式挂载到模态方案。
2. **空壳方案检查**：确认方案已绑定 `Lanczos Method`（`EIGRL`，如 `ND=10`、`NORM=MASS`）、已建模态步（Step），并具备独立输出请求。
3. **输出请求隔离与减容**：模态分析不要与静力学共用同一个 `Output Requests` 对象。应复制出独立的模态输出请求，仅开启 `Displacement` 与 `Effective Mass`，关闭 `Stress` 与 `SPC Forces`（避免 `.op2` 动辄 500–600 MB，并防止修改静力方案输出）。同时留意 `PRINT` 与 `PLOT` 区别，避免无意导出数百 MB 的全节点文本 `.f06`。
4. **物理合理性复核**：除看 `.log` 的 `Normal modes analysis completed` / `Analysis complete  0` 外，还要结合结构刚度量级、对称结构的成对模态及 `.f06` 末尾 `MODAL EFFECTIVE MASS SUMMARY` 评估结果合理性，并在报告中说明模态位移仅表示归一化相对振型而非实际物理变形。

## 输出请求

NX 12 本项目观察到的入口：编辑解算方案 → 工况控制 → 输出请求。值为“无”时，可通过右侧新建图标创建输出请求；也检查步骤是否有独立覆盖。界面版本不同，按实际截图/控件定位，不猜按钮位置。

常用需求为位移、应力和约束反力，节点/单元范围按任务选取。典型 CASE CONTROL：

```text
DISPLACEMENT(PLOT) = ALL
STRESS(PLOT) = ALL
SPCFORCES(PLOT) = ALL
```

它们可以出现在全局或子工况中；核查继承和覆盖，不只搜索某一个位置。OP2 格式参数也需核对。只补临时 DAT 不算修好 SIM，必须使原生解算方案重新导出时保留相同请求。

## 单位与合量

- 必须读本次 DAT 单位声明和实际数值，不能沿用上次工程单位。
- N-mm-s 一致质量单位为 tonne：45钢常见假设密度 7.85e-9 t/mm³，HT200 教学假设 7.15e-9 t/mm³。
- mN-mm-s 一致质量单位为 kg：相应密度为 7.85e-6 和 7.15e-6 kg/mm³；弹性模量和载荷数值也需换算。以上密度是示例，不是材料证书。
- 两种单位制 g 均为 9810 mm/s²；206000 MPa 对应 206000 N/mm² 或 206000000 mN/mm²。
- 合力、合矩须计入坐标系和参考点；平衡的压力或左右销载荷可能整体合力为零，不代表没有局部载荷。旧节点力合量不能直接作为新的机械外力，须分离来源。
- 结果可读后再检查反力平衡、变形方向、刚体运动及局部峰值。手工修改后原来的收敛证据不自动适用。
